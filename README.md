# WEB Zona Fit GYM 
Aplicación WEB creada con **Java** y con el framework de interfaz de usuario de **JavaServer Faces**.
Esta aplicación permite el registro y la gestión de los clientes de un gimnasio accediendo desde un navegador.

## Funcionalidades
- Lista los clientes registrados
- Agregar un nuevo cliente
- Modificar la información de los clientes ya agregados
- Eliminar un cliente
- Contiene mensajes de confirmación de cada una de las acciones

## Requisitos
- Java 21
- Spring Boot 3.1.2
- MySql
- Navegador web

## Instalación
- Clonar el repositorio 
- Abrir el proyecto en tu IDE favorito
- Configurar la base de datos MySQL

## Ejecución
- Seleccionar la clase ZonaFitWeb(src/main/java/gm.zona_fit/ZonaFitWeb)
- Ejecutar la aplicación
- Acceder al navegador web
- En la barra de búsqueda del navegador web colocar la siguiente URL localhost:8080/index.xhtml
